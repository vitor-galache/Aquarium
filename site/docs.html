O que é

O Notesea é um app de anotações para desktop. Você abre uma pasta e cada nota vira um arquivo Markdown dentro dela.

Onde ficam as notas

Na pasta que você escolher ao abrir o app. As subpastas viram pastas na barra lateral. O app guarda só algumas preferências em .notesea/, dentro da mesma pasta. Como são arquivos comuns, dá para fazer backup ou sincronizar com a ferramenta que preferir.

Atalhos

No macOS, os atalhos do editor usam ⌘ no lugar de Ctrl.

Ctrl Shift Espaço Captura rápida (global, configurável)
Ctrl B Negrito
Ctrl I Itálico
Ctrl Shift X Tachado
Ctrl E Código
Ctrl 1 / 2 / 3 Título nível 1, 2 ou 3
Ctrl Shift 8 Lista
Ctrl Shift 7 Lista numerada
Ctrl Shift 9 Lista de tarefas
